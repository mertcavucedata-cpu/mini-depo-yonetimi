# 📦 Mini Depo Yönetim Sistemi (Python OOP)

Python öğrenme sürecimde Nesne Yönelimli Programlama (OOP) prensiplerini pekiştirmek amacıyla geliştirdiğim konsol tabanlı depo ve stok yönetim projesi.

## 🚀 Özellikler
- **Ürün Ekleme:** Ürün kodu, adı, fiyatı ve stok miktarı ile yeni ürün tanımlama.
- **Stok Listeleme:** Depodaki tüm ürünleri ve güncel stok durumlarını görüntüleme.
- **Satış İşlemi:** Stok kontrolü yaparak satış gerçekleştirme ve kalan stoğu otomatik güncelleme.

## 🛠️ Kullanılan Teknolojiler
- **Dil:** Python 3
- **Konseptler:** Class/Object (OOP), List Yapıları, Konsol Menü Yönetimi (CLI)
